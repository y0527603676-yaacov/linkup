# LINKUP — כללים עסקיים

כל הכללים מוגדרים בגרסת ההסכם (`agreement_versions`) ונשמרים כפי שאושרו. שינוי = גרסה חדשה, מכאן והלאה.

## ייחוס (ברירות מחדל לפיילוט)
1. חלון ייחוס: **30 יום** מהקליק.
2. **קופון אישי תקף גובר** על קליק.
3. אחרת — **הקליק האחרון** הזכאי בתוך החלון.
4. **ייחוס אחד להזמנה** לכל תוכנית. אין עמלת LINKUP כפולה.
5. בסיס העמלה: סכום נטו **ללא מע"מ וללא משלוח** (אלא אם הוסכם אחרת).

## מקרים מיוחדים
| מקרה | התנהגות |
|---|---|
| החזר חלקי | רשומה נגדית יחסית: עמלה × (סכום החזר / בסיס) |
| החזר מלא / ביטול | ביטול מלא של יתרת העמלה |
| כמה קופונים של כמה משפיענים | הקופון הראשון שהוחל בהזמנה; השאר נרשמים כראיה בלבד |
| דליפת קופון | נספר (מוסכם בתנאים); החנות יכולה להחליף קופון — חל מכאן והלאה |
| הפניה עצמית (המשפיען קונה בעצמו) | מסומן כחשוד אם מייל/טלפון הקונה = של המשפיען; ממתין לאישור החנות |
| רכישה כאורח | ייחוס רגיל לפי קופון/קליק |
| הזמנות חוזרות | כל הזמנה נבדקת בנפרד בתוך החלון |
| עריכת הזמנה | הפרש הסכום → רשומת `adjustment` |
| אירוע מאוחר / לא בסדר | עיבוד לפי `occurred_at`; מצב סופי נקבע מהמצב העדכני ביותר |
| אין ראיה לייחוס | אין עמלה; מוצג בדוח "לא מיוחס" |
| ראיות סותרות | קופון > קליק; תיעוד שתי הראיות |

## מצבי עמלה
`pending` → אחרי חלון החזרות (ברירת מחדל 14 יום אחרי סטטוס completed) → `approved` → נכנס להתחשבנות.

## פיצול סוכנות
סדר עדיפות: קמפיין ספציפי > משפיען ספציפי > ברירת מחדל של הסוכנות. רק פיצול שהמשפיען אישר. חלק הסוכנות נלקח **מתוך** עמלת המשפיען.

## עמלת פלטפורמה (הצעה — לא מאומתת מסחרית)
- רגיל: **3%** מהמכירות הנטו המיוחסות הזכאיות.
- מייסדים: **2%** ל-6 חודשים מההפעלה.
- מחושבת על אותו בסיס ועוברת את אותם החזרים.
- החנות משלמת ל-LINKUP; LINKUP לא מעבירה את כסף ההזמנה.

## עיגול
חישוב ביחידות קטנות; עיגול חצי-למעלה ברמת הרשומה. סכום ההחזרים לעולם לא עולה על העמלה המקורית.
