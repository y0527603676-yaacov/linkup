# LINKUP — זרימות משתמש

## A. חנות מזמינה משפיען (יעד: פחות מדקה למשתמש חוזר)
1. "הזמן משפיען" ← שם/טלפון/אינסטגרם (שדה אחד חובה).
2. עמלה ממולאת מראש מברירת המחדל של החנות; קמפיין — אופציונלי.
3. LINKUP יוצרת קישור הצעה ציבורי (`/o/{token}`).
4. כפתור שיתוף: WhatsApp / העתקה.
5. המשפיען רואה את התנאים **בלי הרשמה**.
6. "אני מאשר" ← אימות מייל/טלפון בקוד חד-פעמי.
7. נוצר הסכם (גרסה 1, שני הצדדים אישרו).
8. נוצרים אוטומטית קופון אישי בחנות + קישור מעקב.
9. מסך הצלחה: "הנה הקישור והקופון שלך" + "הזמן חנות נוספת" (לולאה ויראלית).

## B. משפיען מזמין חנות
1. "הזמן חנות" ← שם החנות + כתובת אתר.
2. הצעה מוכנה ("אני רוצה לקדם אתכם תמורת X% ממכירות").
3. שיתוף.
4. החנות רואה את ההצעה ← "חברו את החנות" ← התקנת תוסף (מדריך 3 צעדים).
5. אישור תנאים ← שותפות פעילה. נרשם `referral` למשפיען.

## C. סוכנות (שלב 2, הארכיטקטורה קיימת משלב 1)
1. יצירת ארגון סוכנות ← הזמנת משפיענים.
2. כל משפיען מאשר ייצוג ואת אחוז הפיצול.
3. הסוכנות מזמינה חנויות בשם המשפיענים.
4. כל עמלה מתפצלת אוטומטית לפי ההסכם הספציפי ביותר.

## D. מכירה ועמלה
1. לקוח נכנס מהקישור או משתמש בקופון.
2. WooCommerce שומרת הזמנה ← התוסף שולח אירוע חתום.
3. מנוע הייחוס מחליט (קופון קודם לקליק).
4. רשומת עמלה במצב "ממתין".
5. החזרים/ביטולים ← רשומות נגדיות.
6. אחרי חלון ההחזרות ← "מאושר".
7. סוף חודש: דוח התחשבנות לחנות (כמה לשלם לכל משפיען) + חשבונית עמלת LINKUP.
8. החנות משלמת למשפיען ומתעדת ← מוצג "דווח על ידי החנות".
9. המשפיען יכול לאשר קבלה ← "אושר על ידי המשפיען".
