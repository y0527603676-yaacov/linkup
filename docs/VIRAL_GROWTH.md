# LINKUP — מנוע צמיחה ויראלית

## הלולאה הראשונה
חנות → מזמינה משפיען → המשפיען עובד עם חנויות נוספות → מזמין אותן → כל חנות מזמינה עוד משפיענים.

**למה זה עובד:** למשפיען יש אינטרס ישיר — כל חנות שהוא מביא היא הכנסה שלו. לחנות יש אינטרס — משפיען שמגיע עם הצעה מוכנה חוסך לה עבודה.

## מנגנונים (לפי סדר בנייה)
| מנגנון | שלב | הערה |
|---|---|---|
| קישור הצעה ציבורי שנפתח בלי הרשמה | 1 | הליבה |
| קבלת הצעה בלחיצה (תנאים ממולאים) | 1 | |
| "הזמן חנות נוספת" במסך ההצלחה של המשפיען | 1 | הרגע הכי חם |
| שכפול הצעה מוצלחת | 1 | `source_proposal_id` |
| תיוג מקור הפניה לכל ארגון חדש | 1 | בסיס לתגמולים |
| דף שותפים ממותג לחנות (`/p/{store}`) | 2 | משפיענים מגישים מועמדות |
| ייבוא שותפים קיימים (CSV / רשימת קופונים קיימים) | 2 | מעבר מהיר של חנות עם 20 משפיענים |
| הזמנות סוכנות לרשימת המיוצגים | 2 | |
| תגמול הפניה | 3 | רק מהכנסה שנגבתה |

## תגמול הפניה (הצעה לפיילוט)
מי שהביא חנות חדשה מקבל **10% מעמלת LINKUP שנגבתה מאותה חנות, ל-12 חודשים**. דרגה אחת בלבד, ללא תגמול על הרשמה.

## מדידה (`funnel_events`)
הזמנות שנשלחו → נפתחו → אושרו → חנויות שהתחברו → שותפויות פעילות → שותפויות עם מכירה → חנויות חדשות מגיעות ממשתתפים קיימים → הכנסה שנגבתה מחנויות מופנות.

**מקדם ויראלי מעשי:** מספר שותפויות פעילות חדשות שנוצרו מכל שותפות פעילה קיימת בתוך 60 יום. לא נדווח על "צמיחה ויראלית" לפני שיש נתונים אמיתיים.

## גבולות
- אין שליחה אוטומטית המונית. כל הזמנה נשלחת על ידי משתמש, ממכשיר שלו (WhatsApp/העתקה).
- הגבלת קצב ליצירת הצעות למניעת ספאם.
