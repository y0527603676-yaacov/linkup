# LINKUP — תוכנית פיילוט

## יעד
**5 חנויות WooCommerce בישראל** שכבר עובדות עם משפיענים, משלמות עמלת LINKUP אמיתית.

## פרופיל חנות אידיאלי
- WooCommerce פעיל, 100+ הזמנות בחודש.
- כבר עובדת עם 3+ משפיענים בקופונים — ומנהלת את זה באקסל/ידנית.
- תחומים: קוסמטיקה, אופנה, תוספי תזונה, מוצרי בית, ילדים.

## איפה מוצאים
1. קבוצות פייסבוק של בעלי חנויות WooCommerce/וורדפרס בישראל.
2. משפיענים שמפרסמים קודי קופון → החנויות שמאחוריהם.
3. בוני אתרי וורדפרס — כל אחד מכיר 10–30 חנויות.

## הצעת הפיילוט
- **2% ל-6 חודשים** (מחיר מייסדים).
- התקנה מלווה על ידינו (זום של 20 דקות).
- ייבוא ידני של כל המשפיענים הקיימים שלהם.

## מה נבדוק
| שאלה | איך נמדוד |
|---|---|
| האם חנות תשלם? | חשבונית ראשונה שנגבתה |
| כמה מכירות מיוחסות קיימות? | ₪ בחודש לחנות |
| משפיענים מאשרים? | % הצעות שאושרו |
| זמן הפעלת שותפות | דקות מהזמנה ועד קופון פעיל |
| ויראליות | חנויות חדשות שהגיעו דרך משפיענים |
| כלכלה | הכנסה מול עלות תמיכה לחנות |

## תפעול ידני מותר
חיוב בחשבונית ידנית, ייבוא שותפים ידני, תמיכה ב-WhatsApp.

## נקודת החלטה (אחרי 60 יום)
- ≥3 חנויות משלמות ו-≥₪50K מכירות מיוחסות בחודש → ממשיכים לאוטומציה וחיוב אוטומטי.
- פחות → לבדוק מחיר, קהל יעד, או מודל מנוי.
