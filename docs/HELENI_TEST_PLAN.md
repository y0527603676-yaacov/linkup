# תרחיש בדיקה מסחרי — Heleni Jewelry (לביצוע רק באישור נפרד)

מטרה: לוודא בחנות אמיתית את כל המסלול — הפניה ← מכירה ← עמלה ← ביטול/החזר ← חשבון — בלי כסף אמיתי.
כל ההזמנות נוצרות בממשק הניהול של WooCommerce (הזמנה ידנית, בלי סליקה), ונמחקות/מבוטלות בסוף.

| 2 | (לא חובה) התקנת תוסף 0.3.0 | בעל החנות | תוך 15 דקות המוצרים מופיעים ב"מוצרים" |
